## 页面层级

```text
App
├─ 控制：草稿预览 → 画笔/双眼同步 → 发送/保存 → 部件 → 更多编辑/逐灯编辑
│  └─ 表情库：本机/当前面板 → 搜索 → 默认/我的表情
│     ├─ 详情：预览 + 应用/编辑/重命名/复制/导出/删除
│     ├─ 批量选择：复制/导出/删除，显示部分失败
│     └─ 排序：暂存顺序 → 完成提交 / 取消放弃
├─ 文字：草稿输入 → 发送或更新播放 → 预览 → 速度 → 高级同步详情
├─ 口型：预览 → 开始/停止 → 灵敏度 → 识别/校准/口型高级设置
├─ 演出：预览 → 歌曲列表或自定义素材 → 播放/暂停/停止/进度
│  └─ 自定义：脚本与音频分别导入、验证后采用
├─ 设置
│  ├─ 连接：网络概览 → 当前或家庭 Wi-Fi / iPhone 个人热点 / 面板直连热点
│  └─ Debug：概览 | 日志 | 测试 | 原始数据
└─ 设备入口：连接状态、当前输出活动、查看与暂停/停止
```

控制、口型、演出及表情详情在宽窗口使用预览/工具双栏；辅助功能大字体回到单栏。控制、文字、口型和演出预览限制高度，使主要操作更容易到达。

## 行为与数据

- `BoardPlaybackCoordinator` 为手动、自动、文字、口型、演出与 Debug 输出分配会话。发送排队前后检查会话，过期帧与迟到响应不得覆盖新内容。
- 网络请求取消会释放等待中的 continuation 并隔离序号；快速切换连接校验连接代次与 transport 身份；重新连接恢复默认事件订阅。
- 控制和文字草稿原子保存到 App 支持目录；草稿、本机表情库、面板表情库和最近发送成功状态分别处理。实时同步默认关闭，由用户明确打开。
- 本机表情由 `LocalFaceStore` 管理；持久化成功后才发布新状态。支持编辑、重命名、副本、跨库复制、搜索、导入导出、批量删除、撤销本机删除以及暂存排序。默认/受保护表情通过编辑副本使用。
- 面板表情操作检查当前连接代次，避免旧面板的 ID 被用于新面板。面板删除不可撤销；部分失败保留可恢复的信息。
- 文字更新按钮与暂停/停止分开；恢复面板文字不覆盖未发送草稿。口型在离开、后台或断连时释放麦克风，并处理权限请求期间离开的情况。
- 演出素材先验证再采用；导入失败保留旧素材。内置歌曲各自保存音频关联；自定义模式可恢复。失去面板连接时允许本机音频继续，重新向面板同步需要明确操作。

## Wi-Fi 与诊断

手机当前 SSID、面板报告的 SSID 和实际 transport 分开显示。读取手机 Wi-Fi 由用户点按触发，使用公开 API 与定位授权；返回空值显示不可读取，不推断为断网。应用未申请读取用户自定义设备名的特殊 entitlement，个人热点名称使用已确认记录、用户输入或面板扫描选择；不把通用 `iPhone` 名称冒充真实热点 SSID。

Debug 概览显示关键指标及采样时间；缺失数据使用未知/未采样。电源估算仅在所需输入存在时显示。日志区区分应用与固件来源，支持筛选、搜索、冻结显示和脱敏导出。测试区先本机预览，发送和维护操作明确区分。原始数据保留未识别字段供诊断。

新界面字符串提供简体中文、繁体中文、英文和日文；定位权限说明单独本地化。目录校验覆盖 718 个代码键，无遗漏，三种目标语言均无活跃未翻译项。
