UnifontLoading.ttf — GNU Unifont, ASCII subset (U+0020–U+007E)

This file is a subset of the GNU Unifont web font that the project's legacy
WebUI ships as legacy/webui_v1/data/resources/fonts/unifont.woff2
("GNU Unifont WebUI Offline Subset"). It is used only for the boot loader's
"LOADING" label, to match the WebUI's pixel-font look.
